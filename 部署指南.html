✅ 为什么换成了 Server酱
PushPlus 从 2024 年起实名认证要付一两块第三方接口费。Server酱 注册即免费会员,不用实名、不花钱,每天 5 条额度(你只需 3 条),而且正文支持 Markdown 表格和图片,也不用像 ClawBot 那样每天手动激活。

第一步:拿到 Server酱 的 SendKey

  1. 打开 sct.ftqq.com,点登录,用微信扫码。
  2. 扫码后关注它的服务号(方糖 / Server酱),页面会显示你的 SendKey(形如 sct 开头的一串字符),复制备用。
  3. 在微信里给这个服务号发一条测试消息确认能收(可选)。
全程不需要身份证、不需要付费。免费会员每天 5 条,你一天只发 3 条,够用。sctp 开头的 SendKey 代码也支持,不用担心格式。

第二步:GitHub 建仓库并上传代码

  1. 登录 github.com,新建仓库 stock-daily,选 Public,勾选 Add a README。
  2. 把本项目 stock-daily 文件夹里所有文件上传到仓库根目录,包括隐藏的 .github/workflows/daily.yml。
cd stock-daily
git init
git remote add origin https://github.com/你的用户名/stock-daily.git
git add .
git commit -m "init"
git branch -M main
git push -u origin main

第三步:把 SendKey 填进 GitHub

  1. 仓库 → Settings → Secrets and variables → Actions → New repository secret。
  2. 名称填 SERVERCHAN_SENDKEY,值粘贴 SendKey,保存。
工作流已默认用 Server酱。GITHUB_TOKEN 是自动提供的,不用配。PushPlus 那行是可选备份,留空即可(无需实名)。

第四步:开启 Actions 并测试

  1. 仓库点 Actions → 左侧点「每日复盘推送」→ 如有提示点绿色按钮启用。
  2. 点 Run workflow → 选 premarket → 运行。
  3. 等 1-2 分钟,微信服务号里应收到一份盘前报告,含四张指数图。
如果失败:点进运行记录看日志。常见原因:① SendKey 填错或没填 → 检查 Secret;② 服务号取关了 → 重新关注;③ 当天 5 条额度用完 → 等次日或别反复测试。注意每次手动测试也会占额度。
